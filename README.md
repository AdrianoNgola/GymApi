# Sistema de Gestão de Ginásio

Sistema desenvolvido para facilitar a gestão de pequenos e médios
ginásios, permitindo controlar clientes, planos, pagamentos,
mensalidades e entradas.

## Objetivo

Digitalizar e simplificar a gestão dos clientes e pagamentos
dos ginásios.

## Tecnologias

- C#
- ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- JWT
- Swagger
- Git/GitHub
